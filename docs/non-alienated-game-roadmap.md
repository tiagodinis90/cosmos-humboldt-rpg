# Six-month experimental game practice — resumable roadmap

Saved: 2026-10-10. Status: **planned**, not started or promised. Applies across game experiments; COSMOS remains a separate, existing deep project.

## Objectives and definition of success
Explore a portfolio of **up to 30 small games in six months** without treating that count as a productivity obligation. Success means finished experiments when possible, techniques learned, ethical experimentation and relationships with other creators; not revenue, downloads or follower growth. Reassess workload monthly.

The titles are **concept seeds**, not completed or commissioned games. Aim for 3–6 small experiments in a month only when enjoyable and feasible; skipping is explicitly allowed.

## The first five candidate prototypes
1. **Internal Dérive:** a mundane decision narrated by six incompatible internal faculties; clicking changes perspective, not time. 1-hour Twine proof of concept.
2. **Vanishing Logbook:** reading one entry changes another, exploring incomplete knowledge. Keep all destruction inside fictional state; add reset and transparency about game behaviour.
3. **Non-Euclidean Memory:** three rooms, doors whose destinations depend on prior visits; a meaningful spatial surprise with basic orientation/accessibility options.
4. **Permit for the Apocalypse:** escalating administrative forms and conflicting responsibility; a short satire grounded in the player's choices.
5. **Watershed With No Protagonist:** adjust a material/water flow and observe downstream trade-offs; scientific simplification must be clearly indicated.

## Proposed first session — Internal Dérive
- Start a Twine project with six passages/faculties: Observation, Memory, Bureaucracy, Desire, Material Conditions, Imagination.
- Start from one ordinary event: discovering that a familiar place has been closed.
- Each link changes the *interpretation* of this event; each faculty reveals a different, sometimes contradictory observation.
- Add a return link to the start that changes one sentence through state; keep the experience 3–5 minutes.
- Export HTML, read/play it once, archive screenshot/build and write a two-sentence reflection. Only publish with proper credits and intentional licence.
- Completion criterion: navigable and exportable, with at least two genuinely differing interpretations. No requirement to polish visuals.

## Longer-term themes
- Systems and material flows (environmental engineering and simulation)
- Humboldtian observation, memory, ecology and political contradictions (COSMOS, separate project)
- Narrative and identity; urban dérive in Almada and Lisbon
- Collective workshops, swaps, jams and open technical tools

## Pause and return checkpoint
1. Read [the philosophy](./non-alienated-game-practice.md).
2. Do **not** begin by refactoring COSMOS or building a general platform.
3. Select one of five experiments above and define a single-session boundary.
4. Create/export a playable prototype, record what happened, then decide whether to continue.
5. If more collaborators are involved, agree on attribution and compensation before work.
6. Keep Questlog/game-letterbox separate: it is a social game diary, not this creation manifesto.
